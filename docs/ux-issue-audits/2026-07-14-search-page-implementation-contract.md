## 冲突裁决

| 冲突主题 | 旧描述 | 最终执行决定 | 必须有的证明 |

| 普通页大小 | 后半总览写 20 条 | 统一 50 条 | 请求、范围、分页、导出和计数测试 |
| 消息类型 | 后半写五类单选 | 共享九类产品分类，多选；空集合表示全部 | taxonomy 映射与多选请求测试 |

| 浏览模式 | 后半 Phase 5 仅写加载更多 | 手动累积、自动累积、替换式分页三种模式 | 模式切换、range/gap、滚动/active 保留测试 |

| 搜索触发 | 旧实现 debounce 自动搜索 | 后端就绪可自动探测；搜索、重试和刷新只由用户显式触发 | 无隐式请求的交互测试 |
| 排序 | 旧实现有相关性排序 | 没有稳定 score 契约时移除相关性，只保留有事实依据的本地视图整理 | 请求不受本地整理影响的测试 |
| 部分导出 | 文案混用“已加载”“当前页” | 累积模式导出全部 retained ranges；分页模式只导出当前页 | 两种模式的冻结快照导出测试 |
| 全部导出 | 旧前端直接使用已加载数组 | 独立的全量快照任务；后端不完整时禁用，不能前端循环伪装完整 | capability、进度、取消、失败、revision 测试 |

## 最终产品契约

### 1. 统一搜索草稿

`SearchDraft` 包含：

- 关键词。
- 互斥联合范围：全部会话、可解析的当前会话、一个或多个指定会话。
- 零个或多个共享产品消息分类；零个表示全部分类。
- 零个或多个结构化发送者 ID；仅在后端能力可用时出现。
- 可为空的本机自然日起止日期。

关键词进入请求前执行 Unicode NFKC、Unicode 不区分大小写的确定性字面匹配，并以空白分词做 AND 匹配。上限为 200 个 grapheme 和 20 个词项；超限在字段处解释，绝不静默截断。

所有条件只编辑 draft。页面只有一个提交位：关键词有变化或尚无稳定结果时显示“搜索”，只有筛选变化且已有稳定结果时显示“应用筛选”。

### 2. 请求与结果状态机

状态至少分为：

- `SearchDraft`：正在编辑、尚未提交的条件。
- `PendingSearchRequest`：本次显式提交冻结的请求。
- `SearchAppliedRequest`：最后一次成功请求的事实来源。
- `SearchResultSnapshot`：与 applied 请求、后端 snapshot/revision、total 和 retained ranges 绑定的稳定结果。
- 初次请求状态、方向性增量状态、全量导出状态和行级导航状态，彼此独立。

首次成功后才创建稳定结果。替换搜索 pending 时旧结果保持可读；成功后一次性切换 applied 和快照；失败或取消只影响 pending，不污染旧结果。

本地排序、分组、浏览模式和视图切换不改变 applied 请求、不取消网络请求，也不触发搜索。

### 3. 范围与能力失败关闭

范围是以下互斥联合：

- 全部会话。
- 当前会话，必须冻结并携带真实 `chatId`。
- 指定会话，必须至少包含一个真实 `chatId`。

当前会话无法解析时，提交失败关闭并在范围控件处解释；不得静默扩大到全部会话。指定会话为空时同样不能提交。

服务与数据库 readiness 可自动轮询，但恢复就绪后不得自动搜索、自动重试或自动替换结果。错误至少区分服务未就绪、数据库未就绪、超时、可取消和一般请求失败。

### 4. 搜索完整性与 sidecar 契约

普通搜索的发布门槛包括：

- 不受 300 会话默认上限限制。
- 不按每会话最近消息窗口预截断候选集。
- `totalCount` 是该冻结查询的真实全集数量，而不是当前候选数组长度。
- 结果有稳定 `sourceIndex` 或等价基线定位事实。
- 分页使用冻结 snapshot/revision 和确定性 continuation/cursor；新数据不能让 offset 漂移。
- 响应给出安全的匹配来源/元数据，前端不重新解析原始私密消息来猜测命中。
- 支持结构化 sender ID 与显示名，并公开 sender capability。
- 前后端共享九类 taxonomy；不支持的细分类只能映射到“系统与其他”，不能假装精确。
- 时间边界明确为本机自然日转换后的半开或已记录包含性区间，并有边界测试。

扩展必须保持已有 `/api/v1/search` 客户端可用。新前端依据显式 capability 选择增强契约；缺能力时允许诚实的受限状态，但不能把受限结果标为完整、不能开放全部命中导出。

### 5. 三种浏览模式与范围缓存

三种模式共享同一 applied snapshot，普通窗口均为 50 条：

- 手动累积：用户显式向前、向后或加载缺口。
- 自动累积：接近边界时自动请求，仍需可见状态、可取消和失败重试。
- 替换式分页：仅保留当前页，页码切换替换窗口。

累积模式用归一化 `loadedRanges` 和 `gaps` 表达缓存，不允许以 `messages.length` 推导后端 offset。范围合并必须处理相邻、重叠、重复和乱序响应；每个方向/缺口有局部 loading/error/retry。

进入分页前保存 active 结果、滚动锚点和累积 ranges。返回累积模式后恢复；分页内同样保留对应页的阅读位置。浏览模式、排序和分组偏好跨重启记忆，但不能含关键词或私密正文。

按后端基线排序时，缺口位于真实 sourceIndex 位置；本地分组或排序时，用 coverage row 解释当前视图覆盖范围。gap 不参与结果计数、消息键盘导航、选择或导出。

### 6. 日期

日期以本机自然日解释，并在提交时冻结 timezone/offset 语义。结束日期转换必须覆盖 DST，而不能用固定 UTC 午夜或固定 24 小时相加来模拟本地下一日。

允许仅起始、仅结束和完整范围；起始晚于结束时字段级报错并禁用提交。四个快捷范围为今天、近 7 天、近 30 天、本月至今。清除日期只改 draft，不影响稳定结果。

### 7. 最近搜索与隐私

最近搜索仅在成功创建结果快照后记录，最多 5 条，保留 30 天；选中只填 draft。IME 组合期间 Enter 不提交。

开启隐私模式后：

- 最近关键词从 DOM、可访问树和持久化输出中隐藏。
- 暂停新增历史，但不把“开启隐私”解释为永久删除用户原有历史。
- 关键词、正文、路径、sender、会话名和导出内容不得进入普通日志、遥测或错误文本。
- 截图、复制、导出和可访问名称按产品隐私契约处理。

### 8. 结果结构与导航

每条结果至少显示：

- 会话名。
- 发送者。
- 共享产品分类。
- 本地时间。
- 安全高亮的命中片段。
- 命中来源，如正文、文件名、图片说明或结构化卡片字段。
- 媒体占位或对应类型图标。

结果采用连续分隔行，不做独立卡片。整行只有一个可访问打开语义，箭头只作提示；正文可选中，拖选不得导航，键盘一次激活只触发一次。

导航使用稳定来源直接定位；若会话尚未在前端列表中，先按 ID 加载必要上下文，不得要求它已经可见。失败只在当前行显示并允许重试，不能覆盖整个结果面板。返回搜索页恢复完整 draft、applied、snapshot、ranges、active 和滚动位置。

### 9. 零结果、错误与 stale snapshot

零结果建议只修改 draft，例如移除某个条件或切到全部会话；不得自动扩大范围或自动提交。

数据 revision 变化时，旧结果作为显式 stale snapshot 保留，不混入新数据；继续加载和全部命中导出暂停。只有用户选择“刷新搜索”才发起 replacement 请求。

首次失败、replacement 失败、方向性失败、缺口失败、分页失败、导航失败和导出失败均有各自可恢复位置，不使用一个全局错误清空所有内容。

### 10. 导出

导出对话框冻结打开时的 applied 请求、result snapshot、浏览模式、本地排序/分组和 retained ranges。

- 手动/自动累积：部分导出覆盖所有 retained ranges，排除 gaps。
- 替换式分页：部分导出只覆盖当前页。
- 全部命中：独立读取冻结 snapshot 的完整后端基线顺序，不继承仅影响当前视图的本地排序/分组。

全量任务支持预计数量、进行中进度、取消、失败重试、revision 变化和超大集合阈值。重复点击不能产生并发任务。后端 capability 不足时“全部命中”禁用并说明原因。

### 11. 页面与组件边界

- L1 只组合页面与委托事件。
- L2 管理 draft/pending/applied/snapshot、readiness、范围解析、请求、重试、导航和导出编排。
- L3 条件栏、结果工具栏、结果列表、gap/coverage row、日期弹层和导出对话框只接收数据与回调。
- L4 network atom 只编码/解码原始搜索契约；system atom 只包装保存/导航所需系统能力。
- 不引入第二套并行架构，不让 L3 直接请求网络或调用 Tauri。

视觉采用最终原型的克制蓝灰连续工作面：一个实心主动作，其余为边框弱化或无边框命令；不用装饰性卡片堆叠。条件区、结果头和列表保持明确层级。

### 12. 响应式、可访问性与质量门槛

必须验证：

- 320px、390px、720–980px、980–1280px 和至少 1280px。
- 200% zoom、长中文、浅色和深色。
- 完整键盘路径、IME、Escape 分层、弹层/对话框焦点进入与恢复、可见 focus。
- 真实 React 路由上的 axe；静态 HTML 结果不代替应用验收。
- loading、empty、success、invalid、first error、replacement error、cancelled、directional error、gap error、paged error、stale、navigation error、export progress/error/cancel。
- 页面设计评分至少 16/20，且无隐私泄漏、就绪假成功或完整性假承诺。
